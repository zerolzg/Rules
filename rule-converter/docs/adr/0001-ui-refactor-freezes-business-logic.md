# 界面重构冻结业务逻辑

界面从两栏可折叠面板重构为三栏工作区（来源 | 配置 | 预览，订阅地址收进保存后的浮层），但 `app.js` 中的业务逻辑——订阅拉取、解析、合并配置生成、保存/复制/下载——保持行为完全不变，只允许改动 DOM 结构、样式与「接线层」（选择器、事件绑定）。动机是呈现层的流程摩擦与观感，而非行为变更；整体重写逻辑会引入回归风险，而现有生成行为正确且日常依赖。

## Considered Options

- **严格不动 `app.js`**：只改 HTML/CSS。被否——面板级 DOM 钩子会锁死旧分组结构，三栏工作区与浮层做不出来。
- **放开交互流改造**（如自动生成）。被否——超出「功能逻辑不变」的边界。

## Consequences

- 新布局必须提供接线层所依赖的 DOM 钩子（各输入、按钮、状态元素）。
- 手动输入改为边输边解析、订阅地址浮层化，均属接线层变更，不改变最终配置输出。
